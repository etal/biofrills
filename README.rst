BioFrills
=========

Utilities for biomolecular sequence analysis, underpinned by Biopython.

Requires Python 3.12 or later.

License: BSD 2-clause

Installation
------------

This is an ordinary Python package. You can install it from a source checkout
with pip::

    pip install .

This version is not yet released, and its port from Python 2 is in progress:
the library modules and the command-line utilities in scripts/ are still
written for Python 2. The latest release on PyPI, 0.3.1, requires Python 2.7.
The scripts are not installed with the package.
